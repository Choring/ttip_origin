### 2. ✅ 모바일 UI/UX 디테일링
- [x] **하단 플로팅 액션 버튼(FAB)**: 모바일 하단에 '글쓰기' 또는 '북마크/공유' 접근이 용이한 플로팅 버튼 추가.
- [x] **모바일 필터/검색 UI 개선**: 현재 상단에 노출된 검색창을 접이식(Accordion)으로 만들거나, 돋보기 버튼 클릭 시 나타나도록 하여 콘텐츠 영역 최대화.
- [x] **카테고리 탭 스크롤 안내**: 가로 스크롤이 가능한 카테고리 탭 우측에 은은한 그라데이션을 넣어 더 많은 메뉴가 있음을 시각적으로 암시.

### 3. ✅ 검색 및 필터 편의성 증대
- [ ] **검색어 자동 완성/추천**: 검색창 클릭 시 인기 검색어나 최근 검색 태그를 보여주는 간단한 드롭다운 UI 추가.
- [ ] **검색 결과 하이라이트**: 검색 결과 목록에서 제목 내 키워드에 하이라이트(색상 변경) 처리하여 가독성 향상.
- [ ] **비로그인 유저 경험**: 북마크, 좋아요 클릭 시 나타나는 로그인 유도 모달의 문구를 더 매력적으로 수정 (예: "포인트를 쌓고 높은 등급이 되어보세요!").

### 4. ✅ 시스템 안정화 및 성능

- [x] **에러 페이지 디자인**: 404/500 에러 발생 시 서비스 톤앤매너에 맞는 친절한 안내 페이지 제작.
