# 🚀 2026년 4월 17일 진행 목표 (Todo List)

어제까지 모바일 UI의 핵심 요소인 FAB(플로팅 버튼), 필터 UX 개선, 그리고 이미지 지연 로딩 등 성능 최적화를 성공적으로 마무리했습니다.
오늘은 서비스의 **"전문성"과 "정보 전달력"**을 정점으로 끌어올리기 위해 상세 페이지의 데이터 시각화를 강화하고, 검색 엔진 최적화(SEO)를 완벽히 매듭짓는 데 집중합니다.

---

## 📌 주요 개발 작업 (Main Tasks)

### 1. ✅ 게시글 상세 페이지(Show) UI 고도화
- [ ] **카테고리별 정보 카드 디자인**: `Post/Show.vue`에서 `extra_info` 데이터를 활용하여 맛집(영업시간, 주차), 꿀팁(준비물) 등 카테고리 특화 정보를 상단에 프리미엄 카드 스타일로 노출.
- [ ] **이미지 슬라이더(Swiper) 도입**: 게시글 내 여러 이미지가 있을 경우, 단순 나열이 아닌 부드러운 스와이프 슬라이더를 적용하여 모바일 가독성 극대화.
- [ ] **3줄 요약 레이아웃 강조**: `summary` 필드에 인용구(Blockquote)나 전용 배지를 적용하여 본문 진입 전 핵심 내용을 한눈에 파악할 수 있도록 스타일링.

### 2. ✅ 검색 및 내비게이션 UX 완성
- [ ] **검색어 추천 및 히스토리**: 검색창 포커스 시 인기 카테고리나 사용자 추천 태그를 드롭다운으로 제안하여 탐색 편의성 제공.
- [ ] **검색 결과 텍스트 하이라이트**: 검색된 키워드가 포함된 본문/제목 영역에 테마 색상으로 하이라이트를 주어 검색 결과의 연관성 시각화.
- [ ] **브레드크럼(Breadcrumbs) 추가**: 현재 위치를 쉽게 파악하고 상위 카테고리로 즉시 이동할 수 있도록 상세 페이지 상단에 내비게이션 경로 추가.

### 3. ✅ 마케팅 및 SEO 최종 점검
- [ ] **동적 Meta Tag 강화**: 각 게시글의 제목과 본문 요약을 Open Graph 태그에 동적으로 반영하여 카카오톡/페이스북 공유 시 스니펫 퀄리티 향상.
- [ ] **비로그인 유도 문구 개인화**: 북마크/좋아요 시 나타나는 로그인 유도 팝업에 "띱(TTIP)의 모든 꿀팁을 소장해보세요!" 등 서비스 톤앤매너에 맞는 매력적인 카피 적용.
- [ ] **로딩 스켈레톤(Skeleton) 보강**: 데이터 로딩 중 레이아웃 흔들림(Layout Shift)을 방지하기 위해 홈 피드와 상세 페이지에 정교한 스켈레톤 UI 적용.
